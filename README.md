# 📊 Análisis de Ventas: Challenge Alura Store

## 📝 Descripción del Proyecto
Este proyecto forma parte del Desafío de Data Science de **Alura Latam (Oracle Next Education)**. El objetivo principal fue analizar los datos de ventas de una cadena de tiendas minoristas ("Alura Store") para resolver problemas de negocio, identificar ineficiencias y descubrir oportunidades estratégicas.

A través de la limpieza de datos, análisis exploratorio y visualización, se respondieron preguntas clave para la toma de decisiones del "Sr. Juan", dueño del negocio.

## 🛠️ Herramientas y Tecnologías
* **Lenguaje:** Python 🐍
* **Librerías:**
    * `Pandas`: Para la manipulación y unificación de los datasets (4 archivos CSV).
    * `Matplotlib` y `Seaborn`: Para la creación de gráficos estadísticos.
* **Entorno:** Google Colab.

## 🔍 Principales Hallazgos (Insights)

Tras analizar las 4 sucursales, se obtuvieron las siguientes conclusiones estratégicas:

1.  **Facturación:** La **Tienda 1** es la líder en generación de ingresos brutos, siendo el motor financiero de la cadena.
2.  **Satisfacción del Cliente (Alerta):** Existe una **correlación negativa** en la Tienda 1. A pesar de ser la que más vende, tiene la **peor calificación promedio** de satisfacción. La Tienda 3 es la mejor valorada.
3.  **Logística:** Se detectó que la **Tienda 1 tiene los costos de envío más altos**. Esto sugiere que la ineficiencia logística está afectando la experiencia del cliente en esta sucursal clave.
4.  **Productos Estrella:** Las categorías de *Muebles* y *Electrónicos* dominan el volumen de ventas. El producto más vendido es la **"Mesa de noche"**.
5.  **Productos Estancados:** El producto "Celular ABXY" presenta la menor rotación, siendo candidato para liquidación.
